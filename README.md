# DOCO Sportswear

A bright, modern ecommerce storefront for DOCO Sportswear, a Kathmandu-based jersey and football boot shop.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Netlify

Connect this repository to Netlify. Netlify detects Next.js automatically. Use `npm run build` as the build command; no custom publish directory is needed with the Next.js runtime/plugin.

## Replace later

- Update the demo image URLs in `app/page.tsx` and `app/products/[slug]/page.tsx`.
- Replace the OpenStreetMap iframe in `app/page.tsx` with the shop's exact map embed.
- Update product names, prices, and descriptions in the product data.
